# Prototype (design reference, read only)

Clickable prototype of the public site and the admin area, version 33 (November 13, 2026). Plain HTML, CSS and JavaScript with sample data kept in the browser tab. No server code.

Open `index.html` for the public site and `login.html` then any username and password for the admin (`admin.html`). Through XAMPP: http://localhost/real_estate_CKProject/prototype/

When building Django templates, copy the markup and class names from here, copy `styles.css` to `static/css/ck.css`, `admin.css` to `static/css/admin.css` and `vendor/` to `static/vendor/`, and replace the sample data with real queries. See BLUEPRINT.md section 9 for the page to story map.
